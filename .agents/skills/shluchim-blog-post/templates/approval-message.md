# איך מציגים לספי את הטקסט לאישור

## הכלל
- מציגים את **הטקסט העברי הסופי המלא**: כותרת, summary, תאריך, וכל מילה בגוף. לא סיכום, לא ״הנה עיקרי הדברים״, לא קישור לקובץ במקום הטקסט.
- בלי פתיח שבח ובלי הקדמה ארוכה. שורה אחת לפני, שאלה אחת אחרי.
- מחכים לאישור מפורש (״מאושר״, ״סבבה תעלה״, 👍 ברור). שתיקה או ״נראה טוב בגדול״ עם הערות זה לא אישור.
- תיקונים? מתקנים ומציגים שוב את **כל** הטקסט, לא רק את השורה שהשתנתה.

## התבנית

```
הנה הפוסט המלא לאישור:

כותרת: <title>
תקציר: <summary>
תאריך: <date> (התאריך של ההודעה המקורית שלך)

<גוף הפוסט המלא, כולל כותרות הביניים והציטוטים>

מאשר?
```

## הצגת תמונות לאישור (אחרי שהטקסט אושר)

```
תמונה 1 מתוך 4, אחרי הפסקה ״<תחילת הפסקה>״:
<התמונה>
alt: <תיאור קצר בעברית>
```
בסוף: ״אילו מאושרות ואילו לתקן?״ (שאלה אחת).
